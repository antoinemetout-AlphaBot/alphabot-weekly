## 1. Philosophie centrale

**La règle des 70/30 :**
- **70% du temps** = interagir avec d'autres comptes (likes, réponses, follows)
- **30% du temps** = créer son propre contenu

Un compte qui ne fait que publier sans interagir ne grandit jamais. L'algorithme X récompense l'engagement total, pas juste la création.

**Paraître humain = la priorité absolue :**
- Varier les heures de publication (jamais à la même minute exacte)
- Ne jamais poster plus de 4 tweets originaux par jour
- Répondre à ses propres replies dans les 15 minutes (signal fort pour l'algo)
- Avoir des moments "silencieux" (week-ends calmes, soirées sans post)
- Réagir à l'actualité du moment (montres que tu suis les news en temps réel)

## 4. Formules de tweets qui performent

### Type A — Donnée choc (le plus partageable)
```
[EMOJI] [FAIT CHIFFRÉ SURPRENANT en 1 ligne]

[2 lignes d'explication simple]

[Conséquence pour l'investisseur débutant]

#Hashtag1 (1 hashtag max ici)
```
Exemple :
> 📉 Le Bitcoin a perdu -65% en 2022 pendant que le Dollar Index gagnait +15%.
>
> Cette corrélation inverse, peu de débutants la connaissent.
>
> Thread sur pourquoi le dollar est l'indicateur N°1 à surveiller 🧵
>
> #Bitcoin

### Type B — Question ouverte (génère des réponses)
```
Question pour [audience cible] 🇫🇷

[Question simple avec 4 réponses possibles]
→ Option A
→ Option B
→ Option C
→ Option D

[Invitation à répondre]
```

### Type C — Thread (3x plus d'engagement)
```
Tweet 1/N : Accroche forte avec chiffre ou question choc. "Thread complet 🧵"
Tweet 2/N : Premier point avec données
Tweet 3/N : Deuxième point avec exemple concret
...
Tweet N/N : Conclusion + CTA newsletter (naturel, pas agressif)
```

### Type D — Réaction à l'actualité (timing = tout)
```
[EMOJI] [TITRE DE L'ACTU en 1 ligne]

[Ce que ça signifie réellement pour les marchés]

[Angle geopolitique/macro spécifique à AlphaBot]

[Optionnel : mention newsletter si vraiment pertinent]
```

### Type E — CTA doux (1 tweet sur 5 max)
```
📬 Cette semaine sur AlphaBot Weekly :

→ [Point 1 intéressant de l'édition]
→ [Point 2 data/macro]
→ [Point 3 géopolitique]

Gratuit, en français, 100% IA.
👉 [lien site]

#Finance (1 hashtag)
```

## 6. Règles anti-shadowban

Le shadowban X réduit invisiblement ta portée. Pour l'éviter absolument :

❌ **Ne jamais faire :**
- Plus de 4 tweets originaux par jour
- Plus de 2 hashtags par tweet
- Copier-coller le même tweet deux fois
- Suivre/unfollower massivement (limite : 50 follows/jour max)
- Tweeter exactement à la même heure chaque jour
- Mettre des liens dans le tweet principal (les mettre dans le 1er reply à la place)
- Ignorer les réponses à ses tweets

✅ **Toujours faire :**
- Varier les heures à ±15 minutes
- Répondre à chaque reply reçu dans les 30 minutes (prioritaire !)
- Alterner tweets avec et sans lien
- Avoir des pauses naturelles (pas de tweet pendant 4-6h parfois)
- Liker 10-15 posts dans la niche avant de poster son propre tweet

1. Tweet accroche avec stat ou question impossible à ignorer

4-5. Le lien géopolitique/macro (angle unique AlphaBot)
6. Ce que ça signifie pour l'investisseur ordinaire
7. CTA newsletter naturel + lien

**IMPORTANT :** Mettre le lien vers le site uniquement dans le DERNIER tweet du thread, jamais dans le premier (l'algo pénalise les liens dans le tweet d'accroche).
